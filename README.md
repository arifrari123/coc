## 🔧 কীভাবে GitHub Pages এ ডিপ্লয় করবেন

1. নিজের GitHub এ রিপো তৈরি করুন
2. `index.html` আপলোড করুন
3. Settings → Pages → Branch: main, Folder: /(root)
4. Save করুন
5. কিছুক্ষণ অপেক্ষা করুন
6. আপনার সাইট লাইভ হবে! 🎉
