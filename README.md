# ⚔️ Clash of Clans Status Checker

একটি সুন্দর ওয়েব অ্যাপ্লিকেশন যেখানে আপনি Clash of Clans খেলোয়াড় এবং ক্লানের তথ্য দেখতে পারেন।

✅ ক্লানের স্ট্যাটাস চেক করুন  
✅ ক্লান সদস্যদের তথ্য  
✅ বর্তমান যুদ্ধ দেখুন  
✅ যুদ্ধের ইতিহাস  
✅ সুন্দর ডার্ক থিম  
✅ মোবাইল ফ্রেন্ডলি  

## 🚀 শুরু করুন - Vercel এ ডিপ্লয় করুন

### সবচেয়ে সহজ উপায়:

1. **Vercel এ সাইন আপ করুন:** https://vercel.com
2. **GitHub এ রিপো ক্রিয়েট করুন**
3. **সব ফাইল আপলোড করুন** (index.html, api/coc.js, vercel.json)
4. **Vercel এ ইমপোর্ট করুন:** Import → GitHub Repository
5. **Deploy বাটন চাপুন**
6. **সম্পন্ন!** আপনার সাইট লাইভ হবে

### ফাইল স্ট্রাকচার:
```
coc-status-checker/
├── index.html          # মেইন অ্যাপ্লিকেশন
├── api/
│   └── coc.js         # API প্রক্সি (Vercel সার্ভারলেস ফাংশন)
├── vercel.json        # Vercel কনফিগ
└── README.md          # এই ফাইল
```

## 🔧 লোকালি টেস্ট করতে

```bash
# ১. রিপো ক্লোন করুন
git clone https://github.com/YOUR_USERNAME/coc-status-checker.git
cd coc-status-checker

# ২. index.html ব্রাউজারে খুলুন
# (লোকাল টেস্টিং এ API কাজ নাও করতে পারে)

# ৩. Vercel এ ডিপ্লয় করুন
vercel
```
